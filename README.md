#  鳴潮 音骸スコア計算機 / Wuthering Waves Echo Score Calculator

鳴潮（Wuthering Waves）の音骸（Echo）のスコアを計算・評価するためのデスクトップアプリケーションです。
OCR機能（画像認識）による自動入力と、複数の評価アルゴリズムによる詳細なスコアリングに対応しています。

##  主な機能

- **高度なスコア計算**: 4つの評価方法（正規化、比率重視、ロール品質、有効ステータス数）で音骸を多角的に評価。
- **OCR自動入力**: スクリーンショットやクリップボードの画像からステータスを自動認識。
- **一括計算機能**: 複数の音骸をタブで管理し、一括で評価。
- **キャラクター別プリセット**: キャラクターごとに有効なサブステータスと重み付けを設定・保存可能。
- **外観カスタマイズ**: テーマ（ダーク/ライト）の変更や、背景画像・不透明度の調整が可能。

##  セットアップ

### 1. 必須要件
- Python 3.10以上
- Tesseract OCR (画像認識に使用)

### 2. ライブラリのインストール
```bash
pip install -r requirements.txt
```

### 3. Tesseract OCRのインストール
OCR機能を使用するには、システムに Tesseract OCR をインストールする必要があります。
1. [UB-Mannheim Tesseract Wiki](https://github.com/UB-Mannheim/tesseract/wiki) からインストーラーをダウンロード。
2. インストール時、`Additional Language Data` で **Japanese** を選択してください。
3. インストール後、PATHを通すか、デフォルトのインストール先（`C:\Program Files\Tesseract-OCR`）を使用してください。

##  使い方

1. `wuwacalc17.py` を実行します。
   ```bash
   python wuwacalc17.py
   ```
2. **手動入力**: 各タブにステータスを入力し「計算」をクリック。
3. **OCR入力**: 「OCR」タブで画像を読み込み、ステータスを自動抽出。
4. **キャラ設定**: 使用するキャラクターに合わせて重み付けを調整。

##  計算方式について

詳細は [README.html](README.html) またはアプリ内のヘルプを参照してください。
- **正規化スコア**: GameWith式の評価。
- **比率重視**: ステータスの理論最大値に対する比率で評価。
- **ロール品質**: 各ステータスの振れ幅（最高/良/低）を評価。
- **有効ステータス数**: 重みが一定以上のステータスがいくつあるかをカウント。
