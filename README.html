🌊 鳴潮 音骸スコア計算機
Wuthering Waves Echo Score Calculator

📖 日本語

概要

鳴潮（Wuthering Waves）の音骸（Echo）のスコアを計算・評価するためのツールです。

OCR機能（画像認識）による自動入力と手動入力の両方に対応しています。キャラクター別の重み付け設定も利用可能です。

機能

  • スコア計算: 4つの評価方法（正規化、比率重視、ロール品質、有効ステータス数）で評価します。
  • OCR入力: スクリーンショットやクリップボードの画像からステータスを自動で読み取ります。
  • 一括計算: 登録されている複数の音骸を一括で評価します。
  • キャラクター設定: 各キャラクターに固有の有効なサブステータスと重み付け設定を保存・管理できます。
  • 外観カスタマイズ: テーマの変更や背景画像の設定が可能です。背景画像はアプリケーションと同じフォルダに置くことで、フォルダ移動時も設定が維持されます（相対パス対応）。
    詳細なカスタマイズ方法は 外観カスタマイズガイド (Appearance Customization Guide) をご覧ください。

重み付け設定ガイド

このツールでは、複数の計算ロジックに共通の「重み」設定を使用しますが、重みの扱いは方法によって異なります。 すべての方法で正確な評価を行うために、以下の推奨事項に従ってください。

推奨設定

  • 必須ステータス (例: 会心率/会心ダメージ): 1.0 に設定します。
  • 有効ステータス (例: 攻撃力%): 0.5 以上 (例: 0.7 ~ 1.0) に設定します。
    • ⚠️ 注意: 「有効ステータス数方式」では、重みが 0.5 未満のステータスは「有効」と見なされません。
  • ボーナスステータス: 0.1 ~ 0.4 に設定します。
    • 「正規化スコア」には加算されますが、「有効ステータス数方式」には含まれません。
  • 不要なステータス: 0 に設定します。

各計算方式における重みの扱い

4つの計算方式は、それぞれ異なる方法で重み係数を使用します。各方式の特徴を理解することで、より適切な重み設定が可能になります。

方式1: 正規化スコア (GameWith式)

重みの役割: サブステータスの価値を直接的に反映します。

  • 計算方法: 各サブステータスを最大値で正規化（0-1の範囲）し、重み係数を掛けて合計します。
  • 重みの影響: 重みが大きいほど、そのステータスがスコアに与える影響が大きくなります。
  • 推奨設定:
    • 最重要ステータス（会心率/会心ダメージ）: 1.0
    • 重要ステータス（攻撃力%、共鳴効率など）: 0.7 ~ 0.9
    • やや有効なステータス（属性ダメージアップなど）: 0.3 ~ 0.6
    • 不要なステータス（防御力など）: 0
  • 特徴: すべてのサブステータスが重みに応じてスコアに加算されるため、バランスの取れた評価が可能です。

方式2: 比率重視方式 (Keisan式)

重みの役割: ダメージ計算における各ステータスの重要度を表します。

  • 計算方法: サブステータスの比率（実際の値 / 最大値）に重み係数を掛けて合計します。
  • 重みの影響: ダメージ計算式における各ステータスの寄与度を反映します。
  • 推奨設定:
    • 会心率: 1.0 （基準値）
    • 会心ダメージ: 1.0 （会心率と同等の重要度）
    • 攻撃力%: 0.8 ~ 1.0 （キャラクターの基礎攻撃力に依存）
    • 共鳴効率: 0.5 ~ 0.8 （スキル回転率への影響）
    • 属性ダメージアップ: 0.6 ~ 0.9 （ビルドによる）
  • 特徴: 実際のダメージ計算に近い評価が可能で、キャラクターのビルドに応じた細かい調整が重要です。

方式3: ロール品質方式

重みの役割: 各ステータスの「引き」の価値を評価する際の重要度を表します。

  • 計算方法: 各サブステータスの数値品質（最高/良/低）を判定し、品質ポイントに重み係数を掛けて合計します。
  • 重みの影響: 高品質な引きがあった場合のスコアへの貢献度を決定します。
  • 推奨設定:
    • 会心率/会心ダメージ: 1.0 （最高の引きを最大限評価）
    • 攻撃力%: 0.8 ~ 1.0
    • 共鳴効率: 0.7 ~ 0.9
    • その他の有効ステータス: 0.5 ~ 0.8
  • 特徴: サブステータスの「引きの強さ」を重視する評価方法です。重みが高いステータスで高品質な引きがあると、スコアが大きく上昇します。
  • 注意: この方式では、会心率、会心ダメージ、共鳴効率、攻撃力%のみが評価対象です。

方式4: 有効ステータス数方式

重みの役割: ステータスが「有効」かどうかを判定する閾値として機能します。

  • 計算方法: 重みが 0.5 以上のステータスを「有効」としてカウントし、有効ステータス数に応じたボーナス倍率を適用します。
  • 重みの影響:
    • 0.5 以上: 有効ステータスとしてカウントされ、スコアに貢献します。
    • 0.5 未満: 無効と見なされ、スコアに貢献しません。
  • 推奨設定:
    • 必須ステータス（会心率/会心ダメージ）: 1.0
    • 有効ステータス（攻撃力%、共鳴効率など）: 0.5 ~ 1.0
    • やや有効なステータス: 0.5 （ギリギリ有効としてカウント）
    • 不要なステータス: 0 ~ 0.4 （有効としてカウントされない）
  • 特徴: 有効ステータスが5個揃うと最大1.2倍のボーナスが適用されます。重みの細かい数値よりも、0.5 以上か未満かが重要です。
  • 戦略: できるだけ多くのステータスを 0.5 以上に設定することで、5個有効ステータスを狙いやすくなります。

⚠️ 重要な注意事項

  • 共通の重み設定: このツールでは、すべての計算方式で同じ重み設定を使用します。そのため、すべての方式でバランスの取れた評価を得るには、上記の推奨設定を参考にしてください。
  • 0.5の閾値: 「有効ステータス数方式」で有効と見なされるためには、重みを 0.5 以上に設定する必要があります。
  • キャラクター別の調整: キャラクターのビルドやプレイスタイルに応じて、重み設定を調整することで、より正確な評価が可能になります。

Tesseract OCRのセットアップ

OCR機能を使用するには、Tesseract OCRをインストールする必要があります。

  1. インストーラーのダウンロード
    • UB-Mannheim Tesseract Wiki にアクセスします。
    • 最新の tesseract-ocr-w64-setup-v5.x.x.xxxx.exe (64ビット版) をダウンロードします。
  2. 重要なインストール設定
    • インストーラーを実行します。
    • 「コンポーネントの選択」画面で、日本語認識を有効にするために以下の項目がチェックされていることを確認してください：
      • Additional Script Data (download) を展開 → Japanese script にチェック
      • Additional Language Data (download) を展開 → Japanese にチェック
    ⚠️ 注意: これらの言語データファイルがないと、ツールは日本語テキストを認識できません。
  3. 完了
    • デフォルトの場所 (C:\Program Files\Tesseract-OCR) にインストールした場合、このツールは自動的に検出します。
    • それ以外の場所にインストールした場合は、インストールフォルダをWindowsの PATH 環境変数に追加してください。

使用方法

  1. wuwacalc17.pyw を実行します。
  2. 手動モード: 手動でステータスを入力し、「計算」ボタンをクリックします。
  3. OCRモード: 「OCR」タブを選択し、画像を取り込むかクリップボードから貼り付けてテキストを認識させます。
    ※一括自動分類機能（複数枚読み込み）を使用する場合は、「コスト」の表示（COST 4など）を含めて画像を切り取ってください。コストが読み取れない場合、自動分類が正しく機能しないことがあります。
  4. キャラクター設定: 「キャラ設定」ボタンを使用して、特定のキャラクターのプリセットを作成/編集します。
  5. ヘルプ: 「ヘルプ」ボタンをクリックして、このヘルプページを開きます。

Overview

A tool to calculate and evaluate Echo scores for Wuthering Waves.

It supports automatic input via OCR (image recognition) and manual input. Character-specific weighting settings are also available.

Features

  • Score Calculation: Evaluates using 4 methods (Normalization, Ratio, Roll Quality, Effective Stats Count).
  • OCR Input: Automatically reads stats from screenshots or clipboard images.
  • Batch Calculation: Evaluates multiple registered Echoes at once.
  • Character Settings: Set and save effective sub-stats and weights for each character.
  • Customizable Appearance: Supports theme changes and custom background images. Placing images in the application folder maintains settings even if the folder is moved (relative path support).
    For details, please refer to the Appearance Customization Guide.

Weighting Settings Guide

This tool uses a common "Weight" setting for multiple calculation logics, but how weights are handled differs by method. Follow these recommendations to ensure accurate evaluations across all methods.

Recommended Settings

  • Essential Stats (e.g., Crit Rate/DMG): Set to 1.0.
  • Effective Stats (e.g., Atk%): Set to 0.5 or higher (e.g., 0.7 ~ 1.0).
    • ⚠️ Note: In "Effective Stats Count" method, stats with weight less than 0.5 are NOT counted as "effective".
  • Bonus Stats: Set to 0.1 ~ 0.4.
    • Added to "Normalized Score" but NOT included in "Effective Stats Count".
  • Useless Stats: Set to 0.

How Each Calculation Method Uses Weights

The 4 calculation methods use weight coefficients in different ways. Understanding each method's characteristics allows for more appropriate weight settings.

Method 1: Normalized Score (GameWith)

Role of Weights: Directly reflects the value of substats.

  • Calculation: Each substat is normalized by its maximum value (0-1 range), multiplied by the weight coefficient, and summed.
  • Weight Impact: Higher weights mean greater impact on the score.
  • Recommended Settings:
    • Most Important Stats (Crit Rate/DMG): 1.0
    • Important Stats (ATK%, Energy Regen, etc.): 0.7 ~ 0.9
    • Somewhat Effective Stats (Elemental DMG Bonus, etc.): 0.3 ~ 0.6
    • Useless Stats (DEF, etc.): 0
  • Characteristics: All substats contribute to the score according to their weights, enabling balanced evaluation.

Method 2: Ratio-focused Method (Keisan)

Role of Weights: Represents the importance of each stat in damage calculation.

  • Calculation: The ratio of substats (actual value / max value) is multiplied by weight coefficients and summed.
  • Weight Impact: Reflects each stat's contribution in the damage formula.
  • Recommended Settings:
    • Crit Rate: 1.0 (baseline)
    • Crit DMG: 1.0 (equal importance to Crit Rate)
    • ATK%: 0.8 ~ 1.0 (depends on character's base ATK)
    • Energy Regen: 0.5 ~ 0.8 (impact on skill rotation)
    • Elemental DMG Bonus: 0.6 ~ 0.9 (depends on build)
  • Characteristics: Enables evaluation close to actual damage calculation, with fine-tuning important based on character builds.

Method 3: Roll Quality Method

Role of Weights: Represents the importance when evaluating the "roll" value of each stat.

  • Calculation: Judges the numerical quality (Max/High/Low) of each substat, multiplies quality points by weight coefficients, and sums.
  • Weight Impact: Determines the contribution to score when high-quality rolls occur.
  • Recommended Settings:
    • Crit Rate/DMG: 1.0 (maximize evaluation of best rolls)
    • ATK%: 0.8 ~ 1.0
    • Energy Regen: 0.7 ~ 0.9
    • Other Effective Stats: 0.5 ~ 0.8
  • Characteristics: Emphasizes the "strength of rolls" in substats. High-quality rolls on high-weight stats significantly increase the score.
  • Note: This method only evaluates Crit Rate, Crit DMG, Energy Regen, and ATK%.

Method 4: Effective Stats Count

Role of Weights: Functions as a threshold to determine if a stat is "effective".

  • Calculation: Stats with weight 0.5 or higher are counted as "effective", and a bonus multiplier is applied based on the effective stat count.
  • Weight Impact:
    • 0.5 or higher: Counted as effective and contributes to score.
    • Less than 0.5: Considered ineffective and does NOT contribute to score.
  • Recommended Settings:
    • Essential Stats (Crit Rate/DMG): 1.0
    • Effective Stats (ATK%, Energy Regen, etc.): 0.5 ~ 1.0
    • Somewhat Effective Stats: 0.5 (barely counted as effective)
    • Useless Stats: 0 ~ 0.4 (NOT counted as effective)
  • Characteristics: Maximum 1.2x bonus is applied when 5 effective stats are present. The 0.5 threshold is more important than fine-tuning exact weight values.
  • Strategy: Setting as many stats as possible to 0.5 or higher makes it easier to achieve 5 effective stats.

⚠️ Important Notes

  • Common Weight Settings: This tool uses the same weight settings for all calculation methods. To achieve balanced evaluation across all methods, refer to the recommended settings above.
  • 0.5 Threshold: To be considered effective in the "Effective Stats Count" method, weights must be set to 0.5 or higher.
  • Character-Specific Adjustments: Adjusting weight settings according to character builds and playstyles enables more accurate evaluation.

Tesseract OCR Setup

To use the OCR feature, Tesseract OCR must be installed.

  1. Download Installer
    • Visit the UB-Mannheim Tesseract Wiki.
    • Download the latest tesseract-ocr-w64-setup-v5.x.x.xxxx.exe (64-bit version).
  2. Important Installation Settings
    • Run the installer.
    • On the "Choose Components" screen, ensure you check the following items to enable Japanese recognition:
      • Expand Additional Script Data (download) → Check Japanese script
      • Expand Additional Language Data (download) → Check Japanese
    ⚠️ Note: Without these language data files, the tool cannot recognize Japanese text.
  3. Completion
    • If installed to the default location (C:\Program Files\Tesseract-OCR), this tool will automatically detect it.
    • If installed elsewhere, please add the installation folder to your Windows PATH environment variable.

Usage

  1. Run wuwacalc17.pyw.
  2. Manual Mode: Manually enter stats and click "Calculate" (計算).
  3. OCR Mode: Select the "OCR" tab, then import or paste an image to recognize text.
    * When using the batch auto-classification feature (loading multiple images), please ensure the crop area includes the "Cost" display (e.g., COST 4). If the cost cannot be read, auto-classification may not work correctly.
  4. Character Settings: Use the "Character Settings" (キャラ設定) button to create/edit presets for specific characters.
  5. Help: Click the "Help" (ヘルプ) button to open this help page.
